# Project Brief: KiraKira Gacha Web Game

## 1. Project Overview
KiraKira Gacha is a high-fidelity web-based anime character collection game. It features a robust "Gacha" (lucky draw) mechanic, mini-games for resource acquisition, a character synthesis system, and a comprehensive player/admin ecosystem. The project emphasizes a vibrant "KiraKira" anime aesthetic with polished UI/UX.

## 2. Target Audience
- Anime fans and character collectors.
- Casual gamers looking for quick, rewarding sessions.
- Competitive collectors aiming for high-rarity (SSR) achievements.

## 3. Core Features

### 3.1 Gacha System (The Lobby)
- **Pool Types:** Support for both Permanent and Limited-Time event pools.
- **Pull Mechanics:** Supports Single Pulls (x1) and Multi-Pulls (x10).
- **Pity System:** Visual progress bar tracking pulls until a guaranteed high-rarity drop.
- **Visuals:** High-impact character splash art and dynamic pull buttons.

### 3.2 Collection & Gallery
- **Card Archive:** A grid-based gallery showing all acquired characters.
- **Filtering:** Sort and filter by Rarity (SSR, SR, R), Element (Fire, Water, Nature, etc.), and Date Acquired.
- **Character Detail:** View stats, level, and high-resolution art.

### 3.3 Economy & Mini-Games
- **Game Center:** A hub for multiple mini-games (e.g., Puzzle Challenge, Memory Match, Boss Raids).
- **Currency:** Players earn "Points" or "Astral Dust" through gameplay.
- **Shop:** An exchange marketplace where earned points can be traded for character shards, upgrade materials, and consumables.

### 3.4 Progression & Synthesis
- **Synthesis Lab:** A system to fuse materials or duplicate cards to "Limit Break" or upgrade characters.
- **Player Profile:** A dashboard showing collection stats (completion %), total pulls, and unlocked achievements/ribbons.

### 3.5 Administration
- **Director Panel:** A backend interface for game admins to monitor real-time metrics (Active Users, Points Circulation) and adjust card pool probabilities (Drop Rates).

## 4. Visual Identity & Design System
- **Theme Name:** "Vivid Pulse"
- **Style:** Modern Anime / 二次元 (Nijigen).
- **Color Palette:** Primary Pink (#FF77AF), Cyan accents, and soft pastel backgrounds.
- **Typography:** Rounded, bold sans-serif fonts (Plus Jakarta Sans) for a friendly yet energetic feel.
- **UI Elements:** Heavy use of rounded corners (8px+), glassmorphism, and "pop" animations.

## 5. Technical Requirements
- **Platform:** Web (Desktop optimized).
- **Frontend:** Responsive HTML/CSS/JS with a focus on CSS animations for gacha reveals.
- **Interactivity:** Real-time feedback for currency changes and synthesis success rates.

## 6. Future Roadmap
- Social features (Friends list, trading).
- Seasonal leaderboard for mini-games.
- Narrative-driven "Story Mode" chapters.
